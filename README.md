# Graciela Genovés CMS

Sistema de gestión de contenidos para el sitio web de la artista Graciela Genovés.

## Objetivo

Permitir que la artista pueda administrar su sitio web sin conocimientos técnicos, pudiendo:

- Agregar obras
- Editar obras
- Eliminar obras
- Gestionar imágenes
- Actualizar textos del sitio
- Administrar exhibiciones

## Tecnologías

### Backend

- Node.js
- Express
- Supabase

### Frontend

- HTML
- CSS
- JavaScript
